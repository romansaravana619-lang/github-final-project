# Paradise Nursery Shopping Application

## Project Name
**Paradise Nursery Shopping Application**

Paradise Nursery is a React and Redux-based online plant shop. Users can browse houseplants by category, add plants to a shopping cart, change quantities, remove products, view total costs, and use the checkout/continue-shopping controls.

## Main Features
- Paradise Nursery landing page with background image
- About Us company information
- Three plant categories with six unique plants per category
- Product thumbnails, names, prices, and Add to Cart buttons
- Dynamic cart item count
- Redux shopping cart state management
- Increase/decrease quantity and delete cart items
- Total cost calculation
- Checkout placeholder and Continue Shopping action

## Technology
React, Redux Toolkit, React Redux, CSS, and Vite.
