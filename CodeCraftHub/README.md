# CodeCraftHub

Personalized learning dashboard for managing developer-focused course listings.

Features:
- Create, read, update, and delete courses
- Search and filter by level
- Responsive single-page interface
- Browser localStorage persistence

Run:
Open CodeCraftHub/index.html in Google Chrome.
Or run: python -m http.server 8000
Then visit http://localhost:8000/CodeCraftHub/

The final assessment copy-paste answers are in SUBMISSION_ANSWERS.txt.
