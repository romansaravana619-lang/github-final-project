# Express Book Review Final Project

A RESTful online book review application built with Node.js and Express.js.

## Features
- Retrieve all books
- Search by ISBN, author, and title
- Retrieve book reviews
- Register and login users
- JWT + session authentication
- Add/modify and delete reviews
- Axios-based Promise and Async/Await methods

## Run
```bash
cd final_project
npm install
npm start
```

Server runs on port 5001.
